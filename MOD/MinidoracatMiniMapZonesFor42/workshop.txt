description=[h2]✨ What is this[/h2]
description=A [b]server custom-zone addon[/b] for the [b]Minidoracat MiniMap for B42[/b] main MOD:
description=it draws semi-transparent filled areas + outlines + name labels on both the mini-map
description=and the world map.
description=[list]
description=[*] [b]Server-defined zones[/b]: a server-side `zones.json` (writable by external tools, e.g. event-area or reset-zone marker tools) — validated by the server and broadcast to all players in real time; singleplayer reads the local `zones.json` directly
description=[*] [b]Back to `zones.json` (0.3.0)[/b]: game 42.20.0 had dropped `.json` from the Lua file-write extension whitelist (which is why 0.2.0 temporarily used `zones.txt`); [b]42.20.1 added `.json` back[/b], so the canonical file is `zones.json` again. A 0.2.0 `zones.txt` is migrated into `zones.json` automatically on first launch (one-time; any existing `zones.json` is backed up to `zones.premigrate.bak.json` first). External tools should write `zones.json` from now on. [b]This version requires game Build 42.20.1 or later[/b]
description=[/list]
description=[i]Built-in resource points (POI — 14 vanilla-map categories: military/medical/supermarket…) are built into the main MOD as of 0.8.0 — installing the main MOD is enough; this addon is no longer needed for them.[/i]
description=
description=[h2]⚠️ Version requirement[/h2]
description=[b]Requires the main MOD [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3763913359]Minidoracat MiniMap for B42[/url] version 42.19.0-0.8.0 or later[/b] (it provides the zone-layer rendering API and the settings-page action-row API).
description=If the main MOD is missing or too old, this pack silently degrades — no zones are drawn, and the main MOD's other features are unaffected.
description=
description=[h2]🧰 Features[/h2]
description=[list]
description=[*] [b]Display-only markers[/b]: zones are purely visual map overlays — they do not add PVP, safe-zone, or any other gameplay mechanics
description=[*] [b]Server-authoritative sync[/b]: edit `zones.json` and it updates automatically within the poll interval (sandbox-adjustable); admins can also force an instant refresh with [b]/reloadzones[/b]; players joining mid-game see the current zones right away
description=[*] [b]Dual map display[/b]: correct projection and clipping on both the mini-map and the world map
description=[*] [b]Toggles[/b]: the Zone layer master switch (main MOD) / a "Show server zones" per-provider switch (added to the unified settings window by the main MOD from this pack's registration, on by default) — turn it off and the whole layer stops drawing
description=[*] [b]Rectangle zones[/b]: a single zone can be made of multiple rectangles to cover irregular shapes
description=[*] [b]Auto template & generate button[/b]: on first launch a `zones.json` template with four demo zones is generated automatically (localized to the server language); the unified settings window also offers a "Generate zones template" button with a language picker (Traditional/Simplified Chinese, English, Japanese) — a confirm dialog guards against misclicks, the existing file is first backed up to a timestamped `.bak.json`, and on servers it requires the "manage mods" permission
description=[*] [b]enabled field[/b]: set `"enabled": false` on a zone to keep its coordinates but hide it temporarily — no need to delete it
description=[*] [b]Fault-tolerant data[/b]: malformed or over-limit entries are skipped and logged without breaking the rest of the zones
description=[*] [b]Singleplayer & multiplayer[/b]: SP reads the local `zones.json` directly; MP is validated and broadcast by the server
description=[/list]
